# Estructura del proyecto Mi Tienda Web

Proyecto web integrador del curso Fundamentos de Desarrollo Web.

## Carpetas
- **paginas/**: Contiene las vistas secundarias (`catalogo.html` y `contacto.html`) para mantener separada la portada (`index.html`) de las secciones internas.
- **css/**: Almacena las hojas de estilo (`estilos.css`) encargadas de la apariencia visual y el diseño adaptable.
- **js/**: Contiene la lógica e interactividad del sitio (`componentes.js`, `catalogo.js` y `validacion.js`).
- **componentes/**: Guarda fragmentos HTML reutilizables (`encabezado.html` y `pie.html`) que se cargan dinámicamente en todas las páginas.
- **backend/**: Reservada para los scripts del lado del servidor en PHP (incluye `prueba.php` para verificar el entorno).
- **docs/**: Contiene la documentación técnica y descriptiva de la arquitectura del proyecto.

## Convenciones
- Nombres en minúscula, sin espacios ni tildes.
- Una responsabilidad por archivo.
